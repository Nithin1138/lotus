# DropDial Brand Identity & Guidelines

## 1. The Core Brand Promise & Taglines

### The One-Line Promise
> **"Every file format you touch, transformed offline in one gesture."**

### Taglines
- **Primary:** *Drag. Dial. Done.*
- **Secondary (Privacy Focus):** *Your files stay on your machine. Period.*
- **Tertiary (Speed Focus):** *Zero upload time. Zero subscription fees.*

---

## 2. Brand Voice & Personality

The voice of DropDial is **Pragmatic, Precise, and Respectful**.

| Adjective | What We Do | What We Never Do |
| :--- | :--- | :--- |
| **Pragmatic** | State the exact time, bytes, and friction saved. | Never hype with buzzwords like "AI-powered revolutionary synergy". |
| **Precise** | Use exact technical metrics (e.g., "H.264 CRF 23 VideoToolbox encoding at 240 fps"). | Never use vague claims like "ultra-fast magic converter". |
| **Respectful** | Respect the user's attention, screen space, battery, and privacy. | Never nag with popups, upsell spam, or telemetry opt-outs. |

### Pitch Rewrite (Before vs. After)
- **Before:** "DropDial is an AI-enhanced versatile multi-tool suite that leverages modern machine learning algorithms to optimize all your everyday desktop media workflows."
- **After:** "DropDial lives silently in your menu bar. When you drag a WebP image, a 4K video, or a contract PDF onto it, it converts them locally in 2 seconds. No uploads. No subscription."

| # | Candidate Name | Style | Phonetics / Signage | Trademark & Risk Assessment |

| 1 | **DropDial ★** | Compound Descriptive | Crisp, rhythmic, 2 syllables. Memorable icon metaphor (dial wheel). | Clean in Class 9 / 42; domain dropdial.app secured. |

| 6 | **BriskFile** | Functional | Conveys lightness and speed. | Slightly dated Windows 98 feel. |
| 7 | **RadialCut** | Evocative | Fits the circular wheel UI. | Suggests only video editing / cutting. |
| 8 | **ShiftDrop** | Gesture-based | Action-oriented. | Overlaps with keyboard modifier naming. |

**Winner:** **DropDial**. It directly communicates the core interaction: drag and *drop* onto the radial *dial*.

## 4. Visual Identity & Design System

### 4.1 Color Palette

| Token | Hex Value | Role | Contrast Ratio (WCAG) |
| :--- | :--- | :--- | :--- |
| **Deep Obsidian** | `#0D1117` | Canvas background, deep dark mode | Base canvas |
| **Surface Dark** | `#161B22` | Cards, popovers, menu bar background | 14.8:1 against `#FFFFFF` (AAA) |
| **Lotus Teal** | `#00D2B4` | Primary brand accent, action buttons, active dial segment | 4.8:1 against `#0D1117` (AA Large) |
| **Electric Amber** | `#FFB020` | Badges, warnings, conversion status alerts | 8.2:1 against `#0D1117` (AAA) |
| **Pure Chalk** | `#F0F6FC` | Primary headlines and high-contrast labels | 17.1:1 against `#0D1117` (AAA) |
| **Muted Slate** | `#8B949E` | Secondary metadata, file extensions, shortcuts | 4.6:1 against `#0D1117` (AA) |

### 4.2 Typography
- **Primary Interface Font:** `Inter` (Variable Weight 400 to 700) — licensed under SIL Open Font License, native rendering in macOS and Windows.
- **Monospace / Code Font:** `JetBrains Mono` — for file paths, compression ratios, audio bitrates, and terminal snippets.

### 4.3 The Logo & App Icon Brief
- **Visual Motif:** An abstract, continuous precision dial ring rendered in gradient Lotus Teal with a subtle open drop notch at 12 o'clock.
- **Form Factor:**
  - Full-color 512x512 rounded squircle (macOS Big Sur+ guidelines).
  - High-contrast 22x22 monochrome template icon for macOS Menu Bar & Windows System Tray (adapts automatically to Light and Dark mode).
- **Avoid:** Generic floppy disks, literal arrows crossing each other, or photorealistic gears.

## 5. The First Five Touchpoints

1. **The Homepage (dropdial.app):** Instant hero showing an interactive cursor dragging a `.webp` file onto a glowing teal dial that spins and snaps to `.png` in 0.4 seconds. No signup required to download.
2. **The App Launch (First 5 Seconds):** App appears in the menu bar with a subtle 300ms ripple. An unobtrusive floating hint says: *"Drop any file here or press ⌥Space"*.
3. **The First Completed Conversion:** A clean system banner notification: *"Converted to PNG (64% smaller) · Saved to Downloads"*, with an instant "Show in Finder / Explorer" button.
4. **The Order Confirmation Email:** Plain, respectful email containing the 16-character license key in bold monospace, a one-click activation link, and a direct download button. No promotional junk.
5. **The Support & Feedback Loop:** An in-app "Send Note" dialog that attaches anonymized local error logs only if opted-in by the user, answered within 12 hours by the founder.
