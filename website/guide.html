Permissions & Background Detection

Why permissions are needed and where to configure them.

macOS Permissions Essential
What to do
Grant Accessibility permission so DropDial can detect file drags across Finder and desktop windows.
Where to do it
System Settings → Privacy & Security → Accessibility (and Input Monitoring if prompted).
How to do it
  • 1
    On first launch, macOS will present a permission dialog. Click "Open System Settings".
  • 2
    Under Accessibility, find DropDial and toggle the switch to ON (blue). Authenticate with Touch ID or your Mac password.
  • 3
    If DropDial does not appear automatically: Click the + button, navigate to /Applications/DropDial.app, and click Open.
Why Accessibility is needed: macOS requires this permission for any utility that registers global mouse drag events and projects overlay wheels at your cursor. DropDial never records keystrokes.
Windows Permissions Zero Extra Setup
What to do
Windows uses native desktop hooks; no special accessibility or system privilege elevation is required.
Where to do it
Inside DropDial Settings (accessible by right-clicking the tray icon).
How to do it
  • 1
    DropDial starts automatically in the background upon launch.
  • 2
    To ensure DropDial is always ready, check "Run at Windows Startup" in Settings.
  • 3
    If tray notifications don't show, ensure Notifications are enabled in Windows Settings → System → Notifications.
Instant Ready: Because Windows exposes native global low-level hooks, DropDial works immediately after opening without toggling system privacy panels.

Menu Bar / Tray & How to Use

Triggering the radial dials, shortcuts, and managing media tools.

macOS Everyday Use Top Menu Bar
Where to find DropDial
Look for the circular DropDial icon in the top-right macOS menu bar.
How to trigger conversions & actions
  • 1
    Convert File Formats: Drag any file in Finder, hold Shift, and move slightly. The radial conversion wheel appears right around your mouse cursor. Hover over your desired target format (e.g., WEBP, MP4, MP3, PDF) and drop!
  • 2
    Universal Actions Dial: Drag any file and hold Ctrl (⌃). Instantly trigger actions like AirDrop, Copy Path, Terminal here, Float Shelf, or Strip EXIF.
  • 3
    Menu Bar Quick Panel: Click the icon in the menu bar to open Media Tools (Video Trimmer, Audio Bleep, PDF OCR, Image Redact), view conversion history, or configure custom shortcuts.
Converted File Destination: Converted files are saved in the exact same directory alongside your source file with a neat suffix (e.g. photo-converted.webp), or to a custom output folder set in Preferences.
Windows Everyday Use Taskbar System Tray
Where to find DropDial
Look for the DropDial icon in the bottom-right taskbar system tray (click ^ if icons are hidden).
How to trigger conversions & actions
  • 1
    Convert File Formats: Drag any file in File Explorer or your desktop, hold Shift, and drag. The radial wheel blooms around your cursor. Release on the target format to convert instantly.
  • 2
    Universal Actions Dial: Drag any file and hold Ctrl. Select Windows actions like Copy Windows Path, Open in PowerShell, Clean Metadata, or Float Scratchpad.
  • 3
    Tray Quick Menu: Right-click the system tray icon to launch standalone tools, open Settings, check recent conversions, or pause shortcut listening.
Native Windows Notifications: When large video conversions or PDF OCR scans finish, Windows displays an actionable toast notification to open the folder or copy the file.

Troubleshooting

Frequently Asked Setup Questions

The radial dial doesn't pop up when I drag a file and hold Shift. What should I check?

On macOS: Make sure DropDial is granted permission under System Settings → Privacy & Security → Accessibility. Without Accessibility permission, macOS prevents applications from detecting global mouse drag positions outside their own window.

On Windows: Verify that DropDial is running in your taskbar system tray (look in the ^ tray overflow area). Make sure you start dragging the file before or simultaneously with pressing Shift.

Where are my converted files saved?

By default, DropDial saves the newly converted file in the exact same folder as the original file, appending the new extension (e.g. recording.mp4 becomes recording.webm). You can specify a dedicated output folder (such as ~/Downloads or ~/Desktop) in DropDial Settings → Output Directory.

Do I need to be connected to the internet to convert files or use the OCR tool?

Never. DropDial is 100% offline. All conversion engines (FFmpeg, Apple Vision OCR, Windows Tesseract OCR, image codecs) are bundled directly inside the application. No files are ever uploaded to any cloud server.

How many computers can I use my Pro Lifetime license on?

Each DropDial Pro Lifetime license can be used on up to 3 personal computers concurrently (Mac, Windows, or any mix of both). If you upgrade or replace your machine, you can simply transfer your license key.

How do I update to a newer version of DropDial?

Simply download the latest DropDial.dmg (macOS) or DropDial-Setup.exe (Windows) from the website and replace the existing app. All your settings, license activation, and custom hotkeys are preserved automatically.
