Setup & Quick Start

Simple step-by-step instructions from first download to daily shortcuts, permissions, and license activation.

01

Download Package

 macOS (Apple Silicon & Intel) Universal DMG
  1. Download Universal DMG

    Save DropDial.dmg to your Downloads folder.

  2. Or install via Terminal (Optional)
    curl -fsSL https://dropdial.app/install.sh | bash
v1.0.1.6 · 4.2 MB Download DMG
⊞ Windows 10 & 11 (64-bit) Command Line Install
  1. PowerShell (Recommended)

    Open Windows PowerShell (or Windows Terminal) and run:

    irm https://dropdial.app/install.ps1 | iex
  2. Command Prompt (cmd)

    In Command Prompt, launch via PowerShell:

    powershell -Command "irm https://dropdial.app/install.ps1 | iex"
Instant automated installation Auto-creates shortcuts
02

First-Time Launch Approval

 macOS Gatekeeper Approval 1-Click or Settings
  1. Drag to Applications

    Drag DropDial.app into the Applications folder inside the DMG window.

  2. Option A: 1-Line Terminal Command (Recommended)

    Open Terminal, paste this single command, and press Return to approve and launch instantly:

    xattr -cr /Applications/DropDial.app && open /Applications/DropDial.app
  3. Option B: Finder Right-Click (No Terminal)

    In your Applications folder, Right-Click (Control-Click) DropDial.app, select Open, and click Open on the confirmation alert.

  4. Option C: System Settings

    Or open System Settings → Privacy & Security, scroll to Security, and click “Open Anyway”.

✓ One-time setup only. Future launches open instantly.
⊞ Windows SmartScreen No Admin Needed
  1. Automated Installation

    DropDial installs into your user profile and launches automatically.

  2. Click "More info"

    If the blue Defender SmartScreen prompt appears, click "More info".

  3. Click "Run anyway"

    Click "Run anyway" at the bottom. DropDial extracts and creates desktop & Start menu shortcuts automatically.

✓ Installs cleanly inside user profile without registry clutter.
03

Permissions & Background Setup

 macOS Accessibility Required for Drag Detection
  1. Open System Settings

    When prompted on first launch, click Open System Settings (or go to System Settings → Privacy & Security → Accessibility).

  2. Enable DropDial

    Toggle the switch next to DropDial to ON (blue).

  3. Why this is needed

    macOS requires Accessibility permission so DropDial can detect file drag gestures and project radial dials at your cursor. DropDial never collects or transmits data.

✓ 100% offline & private. Zero telemetry.
⊞ Windows Background Hooks Zero Extra Config
  1. Native Windows Support

    Windows manages global mouse drag detection natively. No special accessibility permissions or admin rights are required.

  2. Optional: Launch at Startup

    Right-click the DropDial tray icon → Settings → check "Run at Windows Startup" so DropDial is always ready.

✓ Ready to use immediately upon launch.
04

Shortcuts & Everyday Use

 macOS Gestures Menu Bar Status Item
  1. Format Conversion Dial

    Drag any file in Finder and hold Shift. The circular format dial appears around your mouse. Hover over a target format (e.g. WEBP, MP4, PDF) and drop!

  2. Universal Actions Dial

    Drag any file and hold Ctrl (⌃) to trigger actions: AirDrop, Copy Path, Terminal, Float Shelf, or Strip EXIF.

  3. Menu Bar Quick Panel

    Click the circular DropDial icon in the top-right menu bar for standalone Media Tools (Video Trimmer, Audio Bleep, PDF OCR, Image Redact) and Settings.

Dismiss dial anytime with Esc or by releasing outside petals.
⊞ Windows Gestures Taskbar System Tray
  1. Format Conversion Dial

    Drag any file in File Explorer or your desktop and hold Shift. The radial wheel opens at your cursor. Hover over your desired target format and release.

  2. Universal Actions Dial

    Drag any file and hold Ctrl for quick Windows actions: Copy Path, Open in PowerShell, Strip Metadata, or Float Scratchpad.

  3. Tray Quick Menu

    Right-click the DropDial icon in the bottom-right system tray (click ^ if hidden) for Settings, Media Tools, and recent conversion history.

Dismiss dial anytime with Esc or by releasing outside petals.
05

License Activation

 macOS License 100% Offline Key
  1. Open Preferences

    Click the Menu Bar icon → Preferences... (or press ⌘ + ,).

  2. Enter License Key

    In the License tab, paste your key from your purchase confirmation email (e.g. DDPRO-XXXX-XXXX-XXXX).

  3. Activate

    Click Activate. The key is cryptographically verified locally. Valid for up to 3 personal devices with lifetime updates.

✓ Zero internet connection required for license validation.
⊞ Windows License 100% Offline Key
  1. Open Settings

    Right-click the Taskbar System Tray icon → Settings.

  2. Enter License Key

    Navigate to the License tab and paste your key from your purchase confirmation email.

  3. Activate

    Click Activate. All 7-day trial limits and batch restrictions are removed permanently.

✓ Easily transferable to a new PC anytime.

Quick Troubleshooting

Wheel doesn't appear when dragging?

On macOS, verify System Settings → Privacy & Security → Accessibility has DropDial enabled. On Windows, ensure DropDial is active in your system tray.

Where are converted files saved?

By default, converted files are placed in the exact same folder alongside the original file. You can change this in DropDial Settings to a dedicated folder.

Does DropDial upload files to the cloud?

Never. 100% of conversions, video trimming, and OCR text recognition run locally on your device with bundled native engines.

How do updates work?

DropDial checks for updates automatically in the background. When a new version is ready, a 1-click update prompt appears in your menu bar or system tray. Click to download and relaunch in-place—all settings and lifetime licenses stay completely intact.
