# DropDial 1.0.1.7

DropDial version 1.0.1.7 for macOS and Windows — Universal offline desktop file converter and native media suite.

---

### 🚀 What's New in 1.0.1.7

- **Native Windows Command Prompt `curl` Installation**: Added `install.bat` supporting native command-line installation via Windows built-in `curl.exe` and `tar.exe`:
  ```cmd
  curl -sL https://dropdial.app/install.bat -o install.bat && install.bat
  ```
- **Center Hub Branding**: Updated center hub label and window metadata from "Lotus" to **"DropDial"** with refined typography that fits cleanly inside the hub disk.
- **Refined Float Bar Spacing**: Decreased the vertical gap between the top floating pill bar and the circular wheel disk by 8px for a more compact and polished layout.
- **System-Wide Windows Shortcut Reliability (`WH_KEYBOARD_LL`)**:
  - Implemented a Win32 Low-Level Keyboard Hook (`SetWindowsHookEx`) to intercept **`Alt + Space`** globally from any application and suppress the Windows window system menu.
  - Full support for **`Ctrl + Shift + D`** and **`Ctrl + Shift + L`** as dedicated toggle shortcuts.
  - Instant response for **`Ctrl + Shift + Space`** (Tools mode) and **`F8` / `F9` / `F10`** (Convert / Tools / Actions modes).
- **Drag Shortcut Modifier Flexibility**: Fixed file-drag chord detection so holding **`Ctrl`** alone (or `Ctrl+Shift`) triggers Tools mode, holding **`Shift`** triggers Convert mode, and holding **`Alt`** triggers Actions mode.
- **Robust CI/CD Runtime Mirroring**: Added high-availability GitHub CDN mirrors for FFmpeg portable runtime packaging.

### ⌨️ DropDial Shortcuts Reference

#### Global Shortcuts (Work from any application window)
- **`F8`** *(or `Fn + F8`)*: Open **Formats / Convert Wheel**
- **`F9`** *(or `Fn + F9`)*: Open **Tools Wheel** (Compress, OCR, Trim, Extract Audio)
- **`F10`** *(or `Fn + F10`)*: Open **Actions Wheel** (Floating Shelf, Copy, Move, Reveal)
- **`Alt + Space`** *(Win)* / **`Option + Space`** *(Mac)*: Quick Toggle Wheel at mouse cursor
- **`Ctrl + Shift + D`** *(Win)* / **`Cmd + Shift + D`** *(Mac)*: Conflict-free Quick Toggle Wheel
- **`Ctrl + Shift + L`** *(Win)* / **`Cmd + Shift + L`** *(Mac)*: Quick Toggle Wheel
- **`Esc`**: Dismiss Wheel

#### Drag Gestures (While dragging files from Explorer, Desktop, Browser, or Finder)
- **Hold `Shift` while dragging**: Opens **Formats Wheel** for dragged files
- **Hold `Ctrl` *(Win)* / `Cmd` *(Mac)***: Opens **Tools Wheel**
- **Hold `Alt` *(Win)* / `Option` *(Mac)***: Opens **Actions Wheel** (Floating Shelf, Copy, Move)
- **Press `F8`, `F9`, or `F10` while dragging**: Instantly switches wheel mode

### 🍏 macOS Installation
Download **`DropDial.dmg`** or **`DropDial-macOS.zip`**, drag **DropDial.app** into your **Applications** folder, and launch.
```bash
curl -fsSL https://dropdial.app/install.sh | bash
```

### 🪟 Windows Installation
- **Command Prompt (curl)**:
  ```cmd
  curl -sL https://dropdial.app/install.bat -o install.bat && install.bat
  ```
- **PowerShell (Recommended)**:
  ```powershell
  irm https://dropdial.app/install.ps1 | iex
  ```
- **Manual Download**:
  Download and run **`DropDial-Setup.exe`** or extract **`DropDial-Windows-x64.zip`** and run **DropDial.exe**.
