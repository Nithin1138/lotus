# DropDial 1.0.2.0

DropDial version 1.0.2.0 for macOS and Windows — Universal offline desktop file converter and native media suite.

---

### 🚀 What's New in 1.0.2.0

- **Windows Installer & CLI Provisioning**:
  - **Freshly Compiled Windows Setup**: Delivered the updated NSIS standalone package (`DropDial-Setup.exe`) with Solid LZMA compression (~66 MB), including all offline conversion dependencies.
  - **Fixed CLI Installer Pipeline**: Streamlined `install.ps1` and `install.bat` to consistently fetch the latest 1.0.2.0 build directly without stale version caching.
  - **Process Management**: Integrated automated instance shutdown during upgrades to prevent locked executable errors.

- **Dynamic Checkout & Multi-Gateway Routing**:
  - **Dodo Payments Integration**: Integrated Dodo Payments (Merchant of Record) for automated global VAT/tax compliance, Apple Pay, Google Pay, and international card processing.
  - **Smart Gateway Routing**: Added intelligent real-time payment gateway selection (Razorpay for high-conversion domestic UPI and Dodo Payments for international buyers) with admin dashboard controls.
  - **Real-Time Discount Calculation**: Fixed coupon code verification across both percentage and flat currency discounts (INR and USD).
  - **Instant UI Total Recalculation**: The checkout modal and payment buttons immediately recalculate and reflect the exact discounted price when coupons are applied or removed.
  - **Tier-Aware License Delivery**: License issuance and confirmation emails dynamically reflect the purchased tier (Single = 1 Device, Universal = 2 Devices, Team = 5 Devices) with accurate device slot limits.

- **macOS Universal Client & Engine**:
  - **Universal Binary**: Fully optimized for Apple Silicon (M-Series) and Intel x86_64.
  - **Native Hardware Acceleration**: Apple VideoToolbox integration for high-speed offline video conversion and compression.
  - **Apple Vision OCR & Document Rendering**: Built-in Swift OCR and vector rendering for PDFs, Word documents, and Apple iWork formats without external dependencies.
  - **HiDPI Retina Disk Image**: Beautiful dark-themed DMG installer with zero icon overlap and 1-click drag-to-Applications installation.
  - **Subsystem Caching**: Instantaneous startup via Python interpreter path caching and optimized lookup table processing.

- **Actions Dial & Global Hotkeys**:
  - Enhanced responsive hotkey listeners (`F8`, `F9`, `F10`, `Option+Space` / `Alt+Space`, `Cmd+Shift+D` / `Ctrl+Shift+D`).
  - First-time macOS accessibility permission onboarding flow for the Actions Wheel.

### ⌨️ DropDial Shortcuts Reference

#### Global Shortcuts (Work from any application window)
- **`F8`** *(or `Fn + F8`)*: Open **Formats / Convert Wheel**
- **`F9`** *(or `Fn + F9`)*: Open **Tools Wheel** (Compress, OCR, Trim, Extract Audio)
- **`F10`** *(or `Fn + F10`)*: Open **Actions Wheel** (Floating Shelf, Copy, Move, Reveal)
- **`Alt + Space`** *(Win)* / **`Option + Space`** *(Mac)*: Quick Toggle Wheel at mouse cursor
- **`Ctrl + Shift + D`** *(Win)* / **`Cmd + Shift + D`** *(Mac)*: Conflict-free Quick Toggle Wheel
- **`Ctrl + Shift + L`** *(Win)* / **`Cmd + Shift + L`** *(Mac)*: Quick Toggle Wheel
- **`Esc`**: Dismiss Wheel

#### Drag Gestures (While dragging files from Explorer, Desktop, Browser, or Finder)
- **Hold `Shift` while dragging**: Opens **Formats Wheel** for dragged files
- **Hold `Ctrl` *(Win)* / `Cmd` *(Mac)***: Opens **Tools Wheel**
- **Hold `Alt` *(Win)* / `Option` *(Mac)***: Opens **Actions Wheel** (Floating Shelf, Copy, Move)
- **Press `F8`, `F9`, or `F10` while dragging**: Instantly switches wheel mode

### 🍏 macOS Installation
Download **`DropDial.dmg`** or **`DropDial-macOS.zip`**, drag **DropDial.app** into your **Applications** folder, and launch.
```bash
curl -fsSL https://dropdial.app/install.sh | bash
```

### 🪟 Windows Installation
- **PowerShell (Recommended)**:
  ```powershell
  irm https://dropdial.app/install.ps1 | iex
  ```
- **Command Prompt (curl)**:
  ```cmd
  curl -sL https://dropdial.app/install.bat -o install.bat && install.bat
  ```
- **Manual Installer**:
  Download and run **`DropDial-Setup.exe`** or extract **`DropDial-Windows-x64.zip`** and run **DropDial.exe**.
