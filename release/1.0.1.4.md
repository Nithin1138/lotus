# DropDial 1.0.1.4

DropDial version 1.0.1.4 for macOS and Windows — Universal offline desktop file converter and native media suite.

---

### 🚀 What's New in 1.0.1.4

- **Automatic Background Update Detection**: DropDial now runs periodic background update checks every 30 minutes on both macOS and Windows, automatically detecting newly published updates without requiring manual clicks on "Check for Updates...".
- **Topmost Update Prompts & Native Notifications**: When an update is detected, DropDial immediately displays a topmost update dialog and sends native system notifications (macOS Notification Center and Windows Tray balloon notification with click-to-update action) so updates are never missed.
- **Welcome Window Update Announcement Banner**: Added an integrated update banner card to the Welcome Window featuring a one-click `[Update Now]` action button.
- **Dual-Route API Redundancy**: Both Windows and macOS update engines now feature automatic fallback to GitHub Releases API directly, ensuring immediate update discovery even if edge caches are propagating.
- **Non-Blocking Snooze Flow**: Dismissing an update prompt now snoozes automatic reminders for 4 hours rather than permanently silencing update notifications.
- **Release Automation Hardening**: Fixed release draft status to ensure GitHub Actions automatically publishes releases publicly as latest.

---

### 🍏 macOS Installation
Download **`DropDial.dmg`** or **`DropDial-macOS.zip`**, drag **DropDial.app** into your **Applications** folder, and launch.

### 🪟 Windows Installation
Download **`DropDial-Setup.exe`** or extract **`DropDial-Windows-x64.zip`** and run **DropDial.exe**.
