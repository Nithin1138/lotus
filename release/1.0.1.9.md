# DropDial 1.0.1.9

DropDial version 1.0.1.9 for macOS and Windows — Universal offline desktop file converter and native media suite.

---

### 🚀 What's New in 1.0.1.9

- **End-to-End Performance & Execution Engine Overhaul**:
  - **macOS Hardware Acceleration**: Integrated Apple VideoToolbox (`h264_videotoolbox`) hardware encoding for ultra-fast, energy-efficient video conversions and compression.
  - **Swift Backend Bridge Optimization**: Implemented in-memory binary path caching and instantaneous Python verification in `BackendBridge.swift`, removing disk probe overhead on every conversion.
  - **High-Throughput Dispatch Pipeline**: Replaced sequential conditional checks with an `O(1)` module dispatch table in `worker.py`, bypassing redundant dependency checks during active batch jobs.
  - **Optimized Image & Icon Generation**: Added font caching, hierarchical box downsampling for multi-size icons (`.ico` / `.icns`), and accelerated binary search for target file-size compression.
  - **Fast PDF & Document Processing**: Pre-parsed watermark geometries and batch redaction boxes in `pdftools.py`; streamlined vector document rendering and document conversion pipelines in `documents.py` and `office.py`.
  - **High-Speed Archive Streaming**: Upgraded archive extraction and compression to 1 MB I/O chunk buffers in `archives.py`.
  - **Batch OCR Enhancements**: Hoisted system font discovery and streamlined bounding-box text overlay in `ocr.py`.

- **Enhanced Document Conversion & Fidelity**:
  - Structured layout preservation and high-fidelity rendering for PDF, DOCX, and Apple iWork (Pages, Keynote, Numbers) conversions.

- **License & Plan Display Fidelity**:
  - Correct and immediate display of activated license tiers (Single, Universal, Team) across all desktop UI dialogs, settings, and verification endpoints.

### ⌨️ DropDial Shortcuts Reference

#### Global Shortcuts (Work from any application window)
- **`F8`** *(or `Fn + F8`)*: Open **Formats / Convert Wheel**
- **`F9`** *(or `Fn + F9`)*: Open **Tools Wheel** (Compress, OCR, Trim, Extract Audio)
- **`F10`** *(or `Fn + F10`)*: Open **Actions Wheel** (Floating Shelf, Copy, Move, Reveal)
- **`Alt + Space`** *(Win)* / **`Option + Space`** *(Mac)*: Quick Toggle Wheel at mouse cursor
- **`Ctrl + Shift + D`** *(Win)* / **`Cmd + Shift + D`** *(Mac)*: Conflict-free Quick Toggle Wheel
- **`Ctrl + Shift + L`** *(Win)* / **`Cmd + Shift + L`** *(Mac)*: Quick Toggle Wheel
- **`Esc`**: Dismiss Wheel

#### Drag Gestures (While dragging files from Explorer, Desktop, Browser, or Finder)
- **Hold `Shift` while dragging**: Opens **Formats Wheel** for dragged files
- **Hold `Ctrl` *(Win)* / `Cmd` *(Mac)***: Opens **Tools Wheel**
- **Hold `Alt` *(Win)* / `Option` *(Mac)***: Opens **Actions Wheel** (Floating Shelf, Copy, Move)
- **Press `F8`, `F9`, or `F10` while dragging**: Instantly switches wheel mode

### 🍏 macOS Installation
Download **`DropDial.dmg`** or **`DropDial-macOS.zip`**, drag **DropDial.app** into your **Applications** folder, and launch.
```bash
curl -fsSL https://dropdial.app/install.sh | bash
```

### 🪟 Windows Installation
- **Command Prompt (curl)**:
  ```cmd
  curl -sL https://dropdial.app/install.bat -o install.bat && install.bat
  ```
- **PowerShell (Recommended)**:
  ```powershell
  irm https://dropdial.app/install.ps1 | iex
  ```
- **Manual Download**:
  Download and run **`DropDial.exe`** or extract **`DropDial-Windows-x64.zip`** and run **DropDial.exe**.
