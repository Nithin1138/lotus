# DropDial 1.0.1.6

DropDial version 1.0.1.6 for macOS and Windows — Universal offline desktop file converter and native media suite.

---

### 🚀 What's New in 1.0.1.6

- **Cross-Window Shortcut Reliability**: Fixed global hotkeys failing or behaving erratically in certain application windows (browsers, text editors, Office, terminals, and elevated Administrator windows).
- **Accidental Key Release Conflict Removed**: Eliminated the accidental `Ctrl+Shift` release trigger that was unintentionally firing when selecting text (`Ctrl+Shift+Arrow`) or switching keyboard layout.
- **Double-Trigger & Rapid Dismissal Fix**: Synchronized Windows `RegisterHotKey` (`WM_HOTKEY`) and low-level polling (`GetAsyncKeyState`), eliminating the race condition where the wheel opened and immediately dismissed itself upon key release.
- **Guaranteed Topmost Foreground Activation**: Added Win32 thread input attachment (`AttachThreadInput` and `AllowSetForegroundWindow`) and enforced strict Topmost Z-ordering so the DropDial wheel reliably activates directly in front of any active window, including elevated Admin terminals and full-screen apps.
- **New Alternative Global Shortcuts**: Added **`Ctrl + Shift + D`** (Windows) and **`Cmd + Shift + D`** (macOS) as dedicated conflict-free toggle shortcuts alongside `Alt+Space` / `Option+Space` and `Ctrl+Shift+L` / `Cmd+Shift+L`.
- **Automatic Update Notifications on App Launch**: Both macOS and Windows versions now automatically verify and display an install prompt for new releases upon startup without requiring manual "Check for Updates" clicks.

### ⌨️ DropDial Shortcuts Reference

#### Global Shortcuts (Work from any application window)
- **`F8`** *(or `Fn + F8`)*: Open **Formats / Convert Wheel**
- **`F9`** *(or `Fn + F9`)*: Open **Tools Wheel** (Compress, OCR, Trim, Extract Audio)
- **`F10`** *(or `Fn + F10`)*: Open **Actions Wheel** (Floating Shelf, Copy, Move, Reveal)
- **`Alt + Space`** *(Win)* / **`Option + Space`** *(Mac)*: Quick Toggle Wheel at mouse cursor
- **`Ctrl + Shift + D`** *(Win)* / **`Cmd + Shift + D`** *(Mac)*: Conflict-free Quick Toggle Wheel
- **`Ctrl + Shift + L`** *(Win)* / **`Cmd + Shift + L`** *(Mac)*: Quick Toggle Wheel
- **`Esc`**: Dismiss Wheel

#### Drag Gestures (While dragging files from Explorer, Desktop, Browser, or Finder)
- **Hold `Shift` while dragging**: Opens **Formats Wheel** for dragged files
- **Hold `Ctrl + Shift` *(Win)* / `Cmd` *(Mac)***: Opens **Tools Wheel**
- **Hold `Alt` *(Win)* / `Option` *(Mac)***: Opens **Actions Wheel** (Floating Shelf, Copy, Move)
- **Press `F8`, `F9`, or `F10` while dragging**: Instantly switches wheel mode

### 🍏 macOS Installation
Download **`DropDial.dmg`** or **`DropDial-macOS.zip`**, drag **DropDial.app** into your **Applications** folder, and launch.

### 🪟 Windows Installation
- **PowerShell (Recommended)**:
  ```powershell
  irm https://dropdial.app/install.ps1 | iex
  ```
- **Manual Download**:
  Download and run **`DropDial-Setup.exe`** or extract **`DropDial-Windows-x64.zip`** and run **DropDial.exe**.
