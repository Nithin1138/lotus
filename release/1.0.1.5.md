# DropDial 1.0.1.5

DropDial version 1.0.1.5 for macOS and Windows — Universal offline desktop file converter and native media suite.

---

### 🚀 What's New in 1.0.1.5

- **Lightweight Windows Updates (~15 MB vs 250 MB)**: In-app updates on existing Windows installations now download a dedicated lightweight update package containing only updated application binaries and scripts, preserving existing offline runtimes (Python embeddable and FFmpeg). This reduces download size by over **94%** (from ~250 MB to ~15 MB), reducing update download time from minutes to 2–5 seconds.
- **PowerShell Installer Acceleration**: Suppressed PowerShell's default blue ASCII progress bar (`[ooooooo]`), which previously caused console buffer lockups and throttled download speeds.
- **Silky Smooth Single-Line Terminal Progress**: Added a high-speed streaming downloader with real-time transfer speed, progress bar, and byte counters on a single terminal line without visual artifacts or throughput bottlenecks.
- **Native High-Speed Archive Extraction**: Replaced PowerShell's slow `Expand-Archive` cmdlet with native .NET `ZipFile.ExtractToDirectory`, speeding up extraction by 20x.
- **Existing Installation Auto-Detection**: Running `irm https://dropdial.app/install.ps1 | iex` on a system with DropDial already installed now automatically detects the intact runtime and fetches the fast ~15 MB update package.
- **High-Throughput Update Buffering**: Increased download stream chunk buffer in `UpdateManager` from 8 KB to 64 KB for maximum network wire throughput.

---

### 🍏 macOS Installation
Download **`DropDial.dmg`** or **`DropDial-macOS.zip`**, drag **DropDial.app** into your **Applications** folder, and launch.

### 🪟 Windows Installation
- **PowerShell (Recommended)**:
  ```powershell
  irm https://dropdial.app/install.ps1 | iex
  ```
- **Manual Download**:
  Download and run **`DropDial-Setup.exe`** or extract **`DropDial-Windows-x64.zip`** and run **DropDial.exe**.
