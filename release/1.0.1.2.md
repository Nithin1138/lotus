# DropDial 1.0.1.2

DropDial version 1.0.1.2 for macOS and Windows — Universal offline desktop file converter and native media suite.

---

### 🚀 What's New in 1.0.1.2

- **Centralized Top Announcement Urgency**: The live ticking promotional countdown is now exclusively presented in the sleek top announcement bar. The pricing showcase and hero CTA buttons maintain a clean, distraction-free aesthetic.
- **Configurable 24-Hour Deal Discount**: Admin suite can dynamically configure the promotional discount percentage (default: 10%), automatically propagating across the top banner, checkout calculations, and the `FIRST24` promotional code.
- **Decoupled Architecture & Testing Parity**: Clean delegate-based architecture for `FloatingWheel` and `WelcomeWindow`, resolving multi-window lifecycle constraints and passing 100% of the 70 automated UI and progress test suites.
- **Smooth Drag Modifier Transitions**: Refined `DragShortcutTracker` keyboard chord transitions ensuring the tools menu is preserved when releasing `Ctrl` while dragging.
- **Team Invoicing & Expense Receipts**: Clear itemized receipt generation for company reimbursement on Team tiers.
- **Version Synchronization**: Unified 1.0.1.2 build across macOS Universal binaries (Apple Silicon M-Series + Intel) and Windows .NET engines.

### 🪟 Windows Installation

#### Option 1: Quick Terminal Install (Recommended)
Open **PowerShell** and paste:
```powershell
irm https://dropdial.app/install.ps1 | iex
```

#### Option 2: Standalone Setup Executable (.exe)
Download and run **`DropDial-Setup.exe`** directly from `https://dropdial.app/downloads/DropDial-Setup.exe`.

#### Option 3: Portable ZIP
Download **`DropDial-Windows-x64.zip`**, extract anywhere, and launch `DropDial.exe`.

---

### 🍏 macOS Installation

#### Option 1: Apple Disk Image (.dmg) — Recommended
Download **`DropDial.dmg`** from `https://dropdial.app/downloads/DropDial.dmg`, double-click to open, and drag **DropDial.app** into your **Applications** folder. For first launch, double-click `Open DropDial (First Time)` right inside the DMG window.

#### Option 2: One-Line Terminal Install
Open **Terminal** and run:
```bash
curl -fsSL https://dropdial.app/install.sh | bash
```

#### Option 3: ZIP Archive
Download **`DropDial-macOS.zip`** from `https://dropdial.app/downloads/DropDial-macOS.zip`, unzip, and move to `/Applications`.
