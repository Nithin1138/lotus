# DropDial 1.0.2.5 — Stable Release

DropDial version 1.0.2.5 for macOS and Windows — Universal offline desktop file converter, native media suite, and productivity dial.

---

### 🚀 What's New in 1.0.2.5

- **Windows Wheel Invocation Hotfix**:
  - **Fixed Accidental Wheel Appearance on Drag/Selection**: Fixed an issue where selecting files with `Shift` or dragging files in Windows File Explorer caused the radial dial wheel to appear unexpectedly under the mouse cursor even when no wheel button or shortcut was invoked.
  - **Shortcut-Only Invocation**: Removed automatic drag-motion triggers (`dragShortcuts.Update`) from the Windows polling loop. The radial wheel now appears **exclusively** when you explicitly press a shortcut key (`Alt+Space`, `F8`, `F9`, `F10`, `Ctrl+Shift+D`, `Ctrl+Shift+Space`) or interact directly via the system tray icon or welcome window.
  - **Uninterrupted File Operations**: Normal file drag-and-drop, box selections, and multi-file selections in Windows Explorer and third-party apps now proceed completely cleanly without accidental dial interruptions.

- **macOS & Windows Parity**:
  - **Universal macOS Binary**: Recompiled universal Mach-O binary (`arm64` + `x86_64`) with updated `1.0.2.5` metadata and signed bundle structure.
  - **Consistent Version Synchronization**: Unified assembly versioning across C# (`DropDial.csproj`), NSIS installer (`installer.nsi`), macOS (`Info.plist`), PowerShell build scripts, and backend release APIs.
