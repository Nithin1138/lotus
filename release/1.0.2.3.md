# DropDial 1.0.2.3 — Stable Release

DropDial version 1.0.2.3 for macOS and Windows — Universal offline desktop file converter, native media suite, and productivity dial.

---

### 🚀 What's New in 1.0.2.3

- **Windows Out-of-the-Box Runtime & Office Support**:
  - **Embedded PyMuPDF & Office Libraries**: Bundled native `pymupdf` (fitz), `pdf2docx`, `python-docx`, `python-pptx`, and `openpyxl` directly inside the Windows runtime. Completely eliminates missing module alerts and runtime pip installation failures.
  - **Pruned High-Efficiency Installer**: Re-architected runtime package distribution to keep `DropDial-Setup.exe` at ~90 MB with full LZMA compression while preserving 100% offline document and conversion capabilities.
  - **Expanded Runtime Discovery**: Enhanced Python backend and C# host with multi-path runtime resolution (`sys.prefix`, `runtime/python/Lib/site-packages`, `runtime/Lib/site-packages`).

- **Redesigned Modern Welcome Experience**:
  - **Clean & Impressive First Impression**: Polished the desktop welcome window with a clean layout, clear step-by-step workflow guide, and quick action buttons.
  - **Unobtrusive Background Mode**: Clear privacy and startup options with automatic tray dock guidance.

- **Infrastructure & Multi-Domain Resilience**:
  - **Canonical Domain Support**: Native support across all backend services and client bridges for both `https://dropdial.app` and `https://www.dropdial.app`.
  - **Independent Distribution**: Standalone download endpoints, direct update distribution, and release manifests decoupled from GitHub API rate limits.
  - **CI/CD Pipeline Hardening**: Pinned .NET 8 SDK across GitHub Actions runners and added automated test suite verification for both Windows and macOS builds.
