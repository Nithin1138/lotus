# DropDial 1.0.2.4 — Stable Release

DropDial version 1.0.2.4 for macOS and Windows — Universal offline desktop file converter, native media suite, and productivity dial.

---

### 🚀 What's New in 1.0.2.4

- **Windows Auto-Updater Fix**:
  - **Fixed Version Downgrade Issue**: Resolved a bug where updating from inside DropDial on Windows could download and apply version 1.0.1.1. The internal `UpdateManager` now prioritizes direct GitHub Releases latest assets and eliminates stale URL redirects.
  - **Direct Production Asset Routing**: Reconfigured server redirects (`vercel.json` and `/api/releases`) so that requests for `DropDial-Windows-Update.zip`, `DropDial-Windows-x64.zip`, and `DropDial-Setup.exe` always redirect directly to the latest production release assets hosted on GitHub.
  - **Removed Stale Static Archives**: Purged deprecated legacy binaries from repository and edge caches.

- **Mobile Responsive Website & Admin Portal**:
  - **Fluid Responsive Layout**: Fully optimized `dropdial.app` landing page, download section, CLI copy boxes, and documentation for mobile screens and small viewports.
  - **Mobile Admin Dashboard**: Added touch-friendly navigation, responsive tables, and metrics grid to `admin.html`.

- **macOS & Windows Parity**:
  - **Universal macOS Binary**: Recompiled universal Mach-O binary (`arm64` + `x86_64`) with updated `1.0.2.4` metadata and signed bundle structure.
  - **Consistent Version Synchronization**: Unified assembly versioning across C# (`DropDial.csproj`), NSIS installer (`installer.nsi`), macOS (`Info.plist`), PowerShell build scripts, and backend release APIs.

---

### 📦 Included Binaries

- **macOS Universal Binary**: `DropDial.dmg` & `DropDial-macOS.zip` (Universal `arm64` + `x86_64`)
- **Windows x64 Standalone**: `DropDial-Setup.exe` (NSIS Installer) & `DropDial-Windows-x64.zip` (Portable)
- **Windows In-App Update**: `DropDial-Windows-Update.zip`
