# DropDial 1.0.1.3

DropDial version 1.0.1.3 for macOS and Windows — Universal offline desktop file converter and native media suite.

---

### 🚀 What's New in 1.0.1.3

- fix(windows): update UI verification checks for WelcomeWindow and clean up compiler warnings
- refactor(ui): redesign admin panel and clean up terminal install tabs
- fix: remove language menu option completely
- fix: resolve float bar close X overlap, resize WelcomeWindow for Mac screens, remove bottom languages, and fix Alt+Space toggle
- feat(security): harden website pages and payment APIs, add CLI install options for Windows, and fix macOS wheel drag behavior
- fix(ci): add retry delay to hdiutil convert after detaching disk image in CI runner
- fix(website): lock down banner and strikethroughs with !important, strict master switch, static HTML prices, and v25 cache bust
- fix(website): eliminate page refresh blink for banner and strikethrough prices with synchronous cache
- feat(release): add unified one-command release automation and robust CI publishing
- fix(checkout): stop automatically applying coupon on buy buttons and synchronize discount display
- fix(updater): map actual release assets in releases API, bring update prompts to front, and bundle 1.0.1.2 distribution files
- fix(website): resolve unclosed pricing-grid div tag and normalize card padding & badge positioning

---

### 🍏 macOS Installation
Download **`DropDial.dmg`** or **`DropDial-macOS.zip`**, drag **DropDial.app** into your **Applications** folder, and launch.

### 🪟 Windows Installation
Download **`DropDial-Setup.exe`** or extract **`DropDial-Windows-x64.zip`** and run **DropDial.exe**.
